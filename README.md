# 东秦课表 · Android App

在手机上直接查看**东北大学秦皇岛分校**的空闲教室和自己的课表，无需服务器、无需书签、无需一直开着电脑。

App 内置 WebView 打开学校教务系统，你登录一次后会话保留在 App 内；
之后每次查询由注入脚本在教务页面自己的上下文中读取数据，**不经过任何第三方服务器**，
并且数据会缓存在本地——**再次打开 App 无需登录即可查看上次结果**。

> 非官方工具，数据取自教务系统实时查询，请以教务系统实际结果为准。

---

## 功能

- **一键查空教室** —— 可选查询范围：今天（1 天）/ 明天起 7 天 / 今天起 7 天
- **楼栋 Tab 总表** —— 按「工学馆 / 本部其它 / 南校区」分栏；工学馆按 1–9 层逐层列出，
  其余楼栋各占一行，教室号横向排开（不用左右滑动）
- **时段可折叠** —— 每个时段一张表，点标题收起/展开，6 个时段互不干扰
- **三种状态标记** —— 粗体＝全天有空、下划线＝比上一时段新增、删除线＝下个时段将上课
- **自动过滤非自习教室** —— 实验室、机房、语音室、活动教室、体育场地等不显示
- **本地缓存 + 免登录** —— 结果存在手机本地，再次打开秒开，7 天后提示更新
- **会话保持** —— 持久化 Cookie，多数情况下无需重复登录
- **校徽矢量图标** —— 自适应图标，支持 Android 13+ 主题取色
- **拟物化图标按钮**（v3.0）—— 顶栏的刷新 / 导入 / 查询 / 返回等按钮改为立体渐变底板 +
  矢量图标，主操作用蓝色、次要动作用灰色，状态变化时整排按钮一起切换

### 课表（v2.4 新增）

- **一键导入课表** —— 登录教务后选学期即导入，之后永久离线查看，秒开
- **周视图** —— 12 节 × 7 天网格，跨节次的课自动合并成一个卡片，八色区分不同课程
- **周次切换** —— 按开学日期自动推算当前第几周，可用「上周 / 下周 / 本周」微调
- **滚轮选开学日期** —— 首次导入时用「年 / 月 / 日」三个滚轮选（不用日历网格）；
  之后随时点周次条中间的「第 N 周」改，选任意一天都会自动按那一周的周一起算
- **点空白时段查空教室** —— 网格里没课的格子可点，一下跳到空教室页，直接查**那一组（相邻 2 节）
  的空教室**（你点的那一组会高亮标出），不用再退回来重点一次
  （有课的时段本来就上不了自习，所以点课程卡片改成看详情）
- **时段快捷切换**（v3.0）—— 单时段结果页顶部带一排「1-2 节 / 3-4 节 / …」按钮，
  想换别的时段点一下即可重查，不必退回课表
- **课程详情** —— 点课程卡片看任课教师、上课地点、节次时间与上课周次
- **作息时间** —— 左侧节次列标注东秦真实上课时间（08:00–22:00，共 12 节）
- **导入失败自诊断**（v2.4.1）—— 教务一旦改版导致抓不到课，弹窗会直接给出失败原因、
  响应字节数、`TaskActivity` 命中次数和页面文本片段，可一键复制出来排查

> 课表数据来自树维教务的 `courseTableForStd` 页面。该页面 HTML 表格是空的，
> 课程数据由页面内的 `new TaskActivity(...)` 脚本注入，因此只能从脚本文本中正则提取，
> 教务改版时可能失效 —— 这也是内置诊断的原因。

## 界面

主界面为「楼栋 / 楼层 × 时段」总表，按日期折叠：

```
楼栋 / 楼层     上午1-2节    上午3-4节    下午5-6节   ...
工学馆（按楼层）
  1 层          ⑨ 103 106 107 ...       ③ 503 506 525
  2 层          ⑦ 203 206 207 ...
  ...
  8 层          ⑨ 803 806 807 ...
基础楼          ② 217 308 ...
科技楼          ⑧ 6001-1A (自习室) ...
```

（`⑨` 为该时段该层的空闲教室数量）

### 界面结构（v3.4）

底部三个 Tab，**打开 App 直接进课表**（课表是主页面）：

- **课表** —— 主页。默认停在**本周**，周视图网格，点没课的格子即可查该时段的空闲教室。
  **顶栏不再放任何业务按钮**；没有课表时页面内会给出「登录教务处并导入课表」引导入口
- **空教室** —— 楼栋 × 时段总表。**顶栏放两个动作：刷新（重查空教室）+ 导入（导入课表）**。
  缓存里标出**今天**那一栏，过期会提示刷新；点入后按返回键回到课表，而不是直接退出。
  没有缓存时页面内也给出引导入口（「登录教务处并查询」），
  而不是把教务登录页直接糊上来

> **查询范围永远在登录之后问**。空教室查询需要教务会话，早先的实现是
> `showLogin()` 紧跟着 `askDays()`，结果「查询范围」对话框直接糊在 WebVPN
> 登录页上 —— 人还没登录就被问「查几天」。现在改成：未登录时先跳登录页，
> 用 `pendingAskRange` 记住意图，等 `onPageFinished` 落到 `/eams/` 上再弹范围选择。
> 全项目只有两处调用 `askDays()`，都保证「已经站在教务页上」。
- **更多** —— 设置类功能都收在这里（原生界面，不是网页），以后加功能往这页塞即可：
  - **教务处登录** —— 打开教务系统登录统一身份认证
  - **导入课表** —— 选学期从教务抓取（导入入口在这里，不在课表顶栏）
  - **缓存管理** —— 底部抽屉：每条缓存给出体积 / 条数 / 抓取时间 / 占用比例条，
    单项清除与全部清除分开，各自独立成行避免误触
  - **空教室表网页** —— 网页版空闲教室总表的多个通道入口（通道1 Pages / 通道2 tsiao.io），
    每个通道都标出编号与链接；**在 App 内嵌浏览器里打开**，不跳转外部应用
  - **关于** —— 校徽、版本、应用仓库、复制诊断信息、使用说明

> 顶栏按钮显隐仍由 `applyUi(UiState)` 一处决定；四个内容视图
> （教务 WebView / 结果 WebView / 更多页 / 内嵌浏览器）的互斥切换统一走
> `showContentView(View)`，避免再出现「某个页面盖在最上层导致点了没反应」。
> 顶栏图标用 `btn_icon_flat`：**无底色纯图标**，只有按下时的一圈涟漪。

> 课表顶栏的按钮演进：v3.0 是「导入课表 / 重新导入」两个拟物按钮 →
> v3.1 收敛成一个扁平化刷新按钮 → v3.3 直接移除（导入入口在「更多 → 教务处登录」，
> 空课表页内另有引导入口）。

> 登录态衔接：点查询 / 导入时若未登录，会被重定向到教务登录页。
> 此时 **pending 标记会保留**，用户登完之后流程自动接着跑，不需要再点第二次。
> 中途切走 Tab 会清掉这些标记，避免旧标记在以后浏览教务页时被意外触发。

> 「翻到第 N 周」是临时查看行为，不写盘 —— 每次重开 App 都回到本周；
> 空教室同理，缓存不是当天抓的会明确提示「这是 X 月 X 日的数据」，不会让你误当成今天。

```
        一/9-7   二/9-8   三/9-9   四/9-10  五/9-11
 1 08:00 ┌──────┐   +    ┌──────┐
 2 08:45 │高数  │   +    │计网  │
 3 10:05 ├──────┤   +    └──────┘
 4 10:55 │英语  │   +

```

（`+` 是可点的空白时段，点一下就查这个时间的空闲教室）

## 原理

```
┌─────────────── 手机 App（WebView）───────────────┐
│                                                  │
│  ① 打开 vpn.neuq.edu.cn 教务系统，用户登录一次    │
│         ↓ 会话 Cookie 持久化到 App 本地           │
│  ② 点「查空教室」→ 先加载教务查询页               │
│  ③ 注入 inject.js（同源执行，无跨域限制）         │
│         ↓ 逐时段 POST free!search.action          │
│         ↓ 限速 1.2s/次 + 空结果重试，避开风控     │
│  ④ 解析 table.gridtable → 过滤 → 按楼层归并       │
│         ↓ window.Android.onResult(json)          │
│  ⑤ App 生成表格 HTML 展示，同时写入本地缓存       │
└──────────────────────────────────────────────────┘
```

为什么用 WebView 注入而不是服务端抓取：教务系统接口**没有开放 CORS**，
第三方网页无法读取数据；而学校 WebVPN **对境外与云机房 IP 大量返回 403**，
服务端定时抓取不稳定。WebView 注入让请求发生在教务页面自己的源下，绕开了这两个限制，
也不需要任何服务器。

## 安装

从 [Releases](https://github.com/wanYuea/neuq-classroom-app/releases/latest) 下载 APK（`neuq-classroom-v版本号.apk`）安装即可。

- 需 Android 8.0（API 26）及以上
- 安装时如提示「未知来源」，按系统引导放行

### 使用步骤

1. 打开 App —— 若已有缓存数据会**直接显示上次结果**
2. 首次使用：点「查空教室」→ 进入教务系统 → 登录**统一身份认证**
3. 回到 App 选择查询范围 → 等待十几秒（7 天约 1 分钟）
4. 结果按日期折叠；切「工学馆 / 本部其它 / 南校区」看楼栋，点时段标题可收起展开

## 构建

**环境**：JDK 17+（本仓库使用 JDK 23）、Android SDK（platform 34 / build-tools 34.0.0）、Gradle 8.11.1

```bash
# 1. 指定 Android SDK 路径（local.properties 已被 gitignore）
echo "sdk.dir=/你的/AndroidSDK/路径" > local.properties

# 2. 构建
gradle assembleDebug     # → app/build/outputs/apk/debug/app-debug.apk
gradle assembleRelease   # → app/build/outputs/apk/release/app-release.apk（已签名）
```

### 关于签名密钥

`app/neuq.jks` 是随仓库提供的**演示用**密钥库，口令 `neuq2026`（见 `app/build.gradle`）。

它的存在只是为了让 `assembleRelease` 开箱即可运行。**请勿用于正式发布**——
正式分发请自行生成密钥并妥善保管，可用环境变量覆盖而无需改动代码：

```bash
export NCQ_KEYSTORE=/path/to/your.jks
export NCQ_STORE_PASS=你的库口令
export NCQ_KEY_ALIAS=你的别名
export NCQ_KEY_PASS=你的私钥口令
```

## 教室过滤规则

为只保留**可自习**的教室，以下条目会被排除（规则对齐 [TsiaohanWang/neuq-classroom-query](https://github.com/TsiaohanWang/neuq-classroom-query)）：

| 类别 | 内容 |
|---|---|
| 设备配置 | 体育教学场地、机房、实验室、活动教室、研讨室、多功能、智慧教室、不排课教室、语音室 |
| 整栋排除 | 大学会馆、旧实验楼 |
| 数据异常 | 楼栋或设备配置为空、容量为 0、名称非房间号（如「具体安排以开课部门通知为准」） |

名称会做规范化：「工学馆410」→ `410`；「自主学习室C科技楼6001-1A」→ `6001-1A (自习室)`。

实测在本校某一周的全量数据中，约 21500 条原始记录经过滤后保留约 11000 条。

## 已知限制

- **依赖教务页面结构**（表格 class `gridtable`）。教务系统改版后需同步调整 `inject.js`。
- **首次必须手动登录一次**。统一身份认证不支持程序代填密码，App 也不会保存你的密码。
- **查询有节流**。每次查询逐时段串行请求（约 1.2 秒/次），7 天约需 1 分钟；这是为规避教务
  「请勿过快点击」风控，进度条会实时显示。
- **可能被限流**。若同一天各时段返回的教室数量完全相同，App 会提示可能触发了风控，稍后重试即可。
- **节假日调休**期间教务数据可能未同步，导致空教室表与实际情况不符。
